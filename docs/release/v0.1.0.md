# @tanstack-start/theme v0.1.0

Initial release of the reusable theme library for TanStack Start applications.

## Highlights

- Added a factory-based theme module for creating app-specific theme controllers.
- Introduced TanStack Start cookie-backed theme persistence through the default server function.
- Added safe theme parsing and normalization for raw cookie or server values.
- Preserved `system` as a real theme class token instead of resolving it to `light` or `dark` in JavaScript.
- Added the migration-friendly React hook API:

  ```ts
  const { theme, setTheme } = useTheme();
  ```

- Added `ThemeProvider` as the bridge from TanStack Start router context into the client theme store.
- Added `hydrateTheme()` for non-persisting server/router synchronization.
- Supported optional custom persistence through the `persistTheme` override.
- Exposed `themeConditions` and `createThemeConditions()` for CSS selectors and Tailwind v4 custom variants.
- Added low-level `applyTheme()` support for applying theme classes and `data-theme` metadata to `<html>`.
- Kept the package source-first for Vite and TanStack Start consumers, without requiring a package-level `dist` build step.

## Core behavior

A theme is treated as the exact CSS class token applied to the document root.

For example, when the selected theme is `system`, the document remains:

```html
<html class="system" data-theme="system"></html>
```

The library does not resolve `system` in JavaScript. CSS owns the final visual behavior through selectors, Tailwind variants, and `prefers-color-scheme` media queries.

## TanStack Start integration

The intended flow is:

1. Read the persisted theme on the server.
2. Normalize it with `parseTheme()`.
3. Put the parsed theme into router context.
4. Render the root document with the theme class and `data-theme` attribute.
5. Pass the router-context theme into `ThemeProvider`.
6. Use `useTheme()` in UI controls.

This keeps router/server state as the initial source of truth and avoids a singleton-store-first hydration flow.

## Public API

This release includes:

- `createTheme()`
- `createThemeConditions()`
- `ThemeProvider`
- `useTheme()`
- `setTheme()`
- `hydrateTheme()`
- `parseTheme()`
- `isTheme()`
- `applyTheme()`
- `themeConditions`
- `themeStore`
- `$infer.Theme`

## Notes

This version focuses on the foundation: typed theme configuration, safe parsing, DOM application, server persistence, and TanStack Start-friendly hydration. Future releases can build on this with richer token conventions, additional adapters, and higher-level UI helpers.
