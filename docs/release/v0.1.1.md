# @tanstack-start/theme v0.1.1

Patch release preparing the standalone package for npm publishing.

## Changelog

### Package publishing

- Marked the package as publishable by setting `private` to `false`.
- Added public npm publish metadata through `publishConfig.access`.
- Switched the package typecheck script from `tsgo --noEmit` to `tsc --noEmit`.
- Added TypeScript 7 as a development dependency for local verification.

### Theme hydration model

- Documented the split between `ThemeInitScript` and `ThemeProvider`:
  - `ThemeInitScript` updates `<html>` classes/data before React hydration to prevent visual flash.
  - `ThemeProvider` initializes React Context from router context so `useTheme()` sees the provider value on first render.
- Clarified that `ThemeInitScript` does not initialize React state or TanStack Store state.
- Clarified that route `beforeLoad`, router `hydrate`, and `useEffect` should not be required for initial React theme state.

## Verification

```sh
pnpm run typecheck
pnpm pack --dry-run
```
