# @tanstack-start/theme v0.1.1

Patch release preparing the standalone package for npm publishing.

## Changelog

### Package publishing

- Marked the package as publishable by setting `private` to `false`.
- Added public npm publish metadata through `publishConfig.access`.
- Switched the package typecheck script from `tsgo --noEmit` to `tsc --noEmit`.
- Added TypeScript 7 as a development dependency for local verification.

## Verification

The release was verified with:

```sh
pnpm run typecheck
pnpm pack --dry-run
```

The npm dry run includes only the intended published files:

```txt
package.json
README.md
src/index.ts
src/schema.ts
src/server.ts
src/type.ts
```
